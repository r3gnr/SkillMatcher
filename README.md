# SkillMatcher

**SkillMatcher** — это десктопное приложение для автоматического поиска и ранжирования стажировок в сфере ИТ на основе технических навыков пользователя.

Приложение собирает вакансии с сайта HeadHunter, извлекает технические навыки с помощью специально обученной модели распознавания именованных сущностей (NER) и ранжирует вакансии в зависимости от их соответствия профилю навыков пользователя.

## Возможности

- **Сбор вакансий** — получение ИТ-вакансий с помощью API HeadHunter.
- **Извлечение навыков** — определение технических навыков в описаниях вакансий на русском языке с помощью специально обученной модели NER.
- **Нормализация навыков** — нормализация извлечённых названий технологий и языков программирования.
- **Классификация требований** — различение обязательных и дополнительных навыков.
- **Сопоставление навыков** — сравнение требований вакансий с компетенциями пользователя.
- **Ранжирование вакансий** — ранжирование вакансий в соответствии с совместимостью навыков.
- **Графический интерфейс** — взаимодействие с приложением через графический интерфейс пользователя на основе PySide6.

## Модель (NLP)

Приложение использует специально обученную модель NER для извлечения ИТ-навыков из описаний вакансий на русском языке на базе spaCy (базовая модель ru_core_news_lg).

Извлечённые сущности впоследствии обрабатываются компонентами нормализации и сопоставления навыков.

**Модель:** https://huggingface.co/r3gnr/skill-matcher-ner-ru

## Установка

**1. Клонирование репозитория**

```bash
git clone https://github.com/r3gnr/SkillMatcher.git
cd SkillMatcher
```

**2. Настройка окружения**

```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate     # Для Windows
```

**3. Установка зависимостей**

```bash
pip install -r requirements.txt
```

**4. Подготовка модели**

В коде по умолчанию ожидается, что веса кастомной NER-модели находятся в локальной директории ./custom_ner_lg.
Скачайте модель с [Hugging Face](https://huggingface.co/r3gnr/skill-matcher-ner-ru) и поместите в папку проекта.

**5. Переменные окружения**

Скопируйте .env.example и переименуйте в .env и укажите токены доступа для API HeadHunter по примеру.

## Использование

Запустите приложение:

```bash
python main.py
```

**Как работать:**
1. Введите поисковый запрос (например, Python backend стажировка).
2. Выберите регион из выпадающего списка и укажите лимит вакансий (до 5000).
3. Нажмите «Загрузить». Приложение соберет вакансии и очистит их от HTML-тегов.
4. Введите ваши навыки через запятую (например: Python, SQL, Git, FastAPI).
5. Нажмите «Анализировать навыки». Таблица заполнится вакансиями, отсортированными по убыванию оценки.

## Технологии

- **Python** — логика приложения
- **PySide6** — графический интерфейс пользователя
- **spaCy** — обработка естественного языка и распознавание именованных сущностей
- **pymorphy3** — морфологическая обработка
- **BeautifulSoup4** — разбор HTML и очистка текста
- **HeadHunter API** — сбор данных о вакансиях
- **RapidFuzz** — нечеткое сравнение строк

## Оценка точности и производительности

Проект включает в себя инструменты для валидации ML-пайплайна, что обеспечивает предсказуемость результатов при масштабировании.

**1. Оценка точности (Evaluation)**

Скрипт evaluate_pipeline.py рассчитывает Precision, Recall и F1-score (Macro/Micro) на размеченном датасете (ground_truth.json), а также проводит анализ ошибок.

**Пример запуска:**
```bash
# Генерация шаблона для ручной разметки
python evaluate_pipeline.py --generate_template

# Оценка модели
python evaluate_pipeline.py --ground_truth ground_truth.json
```

**2. Бенчмаркинг производительности**

Скрипт benchmark.py измеряет время инференса на вакансию, гарантируя, что пайплайн укладывается в заданные показатели. Отчет сохраняется в формате JSON.

**Пример запуска:**
```bash
python benchmark.py --input vacancies.json --sizes 50 100 200
```
